# Momontanha

Relatos de trilhas, travessias e escaladas nas serras do Paraná, a **croquiteca** da região e
croquis próprios em página web e PDF versionado.

- Site: https://lcechinel.github.io/momontanha/
- Conteúdo em Markdown (`src/content/`), site em [Astro](https://astro.build), publicado no GitHub Pages.
- Os PDFs dos croquis são gerados a cada publicação e cada versão fica guardada nas Releases.

```sh
npm install
npm run dev     # servidor local
npm run build   # site + PDFs em dist/
```

Detalhes de estrutura e fluxo de trabalho em [CLAUDE.md](CLAUDE.md).
